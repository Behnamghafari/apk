درباره ApiX نسخه 1.6.0
ApiX
یک ابزار کاربردی برای برنامه‌نویسان و توسعه‌دهندگان API؛ برای ساخت، ارسال، بررسی و آزمایش درخواست‌های شبکه، مستقیم روی اندروید.
امکانات برنامه
۱. پشتیبانی از چند پروتکل
ارسال درخواست‌های REST با متدهای GET، POST، PUT، PATCH، DELETE، HEAD و OPTIONS؛ اجرای درخواست‌های GraphQL و برقراری ارتباط WebSocket با ws و wss.

۲. ساخت و تنظیم درخواست
مدیریت Query Parameters، هدرها، انواع احراز هویت شامل Bearer Token، Basic Auth و API Key؛ ارسال بدنه JSON، متن خام و فرم URL Encoded.

۳. محیط‌ها و متغیرها
تعریف چند محیط مثل Development و Production، نگهداری متغیرها و استفاده از آن‌ها در آدرس، پارامترها، هدرها، احراز هویت و بدنه درخواست. امکان خروجی گرفتن و وارد کردن محیط‌ها نیز وجود دارد.

۴. اسکریپت و تست خودکار
اجرای Pre-request Script پیش از ارسال و Tests Script پس از دریافت پاسخ؛ امکان تعریف متغیر و بررسی نتیجه تست‌ها.

۵. بررسی پاسخ سرور
نمایش پاسخ در بخش‌های JSON، Raw، Diff، Headers و Cookies؛ مشاهده وضعیت و زمان پاسخ، اعتبارسنجی و مرتب‌سازی JSON، کپی یا ذخیره پاسخ.

۶. مدیریت درخواست‌ها
ثبت تاریخچه، ذخیره درخواست‌ها در مجموعه‌های دلخواه، اجرای گروهی درخواست‌ها و تهیه گزارش نتیجه اجرا.

۷. ابزارهای توسعه
تولید کد JavaScript Fetch، Python Requests و PHP cURL؛ رمزگشایی Header و Payload توکن JWT؛ جست‌وجو در پاسخ‌ها؛ انتقال مجموعه‌ها با JSON؛ اجرای گروهی و زنجیره‌کردن درخواست‌ها با خروجی درخواست قبلی.
این برنامه برای کمک به توسعه و عیب‌یابی API ساخته شده است. هنگام کار با سرویس‌های واقعی، از اطلاعات ورود و توکن‌ها محافظت کن و درخواست‌ها را فقط به سرویس‌هایی ارسال کن که مجاز به آزمایش آن‌ها هستی.

تاریخچه درخواست‌ها


مجموعه‌ها 
نمونه‌های آماده JSONPlaceholder و تست‌های HTTP در مجموعه‌های پیش‌فرض قرار دارند. اجرای مجموعه، درخواست‌ها را به‌ترتیب می‌فرستد. برای زنجیره‌کردن درخواست‌ها، خروجی درخواست قبلی را با متغیرهایی مثل {{prev.access_token}}، {{prev.status}} یا {{prev.raw}} در درخواست بعدی استفاده کن.


مدیریت محیط‌ها 
محیط فعال را از فهرست بالای درخواست انتخاب کن. متغیرها در آدرس، Query، هدرها، Authorization، بدنه و پیام WebSocket با قالب {{base_url}} جایگزین می‌شوند.
