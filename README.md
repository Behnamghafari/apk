# APK Collection

مجموعه برنامه‌های اندرویدی مستقل با Kotlin.

## برنامه‌ها

- [Salon Link](apps/salon-link) — برنامه‌ای با آیکون آرایشگری برای ذخیره آدرس سایت و باز کردن آن با هر بار اجرای برنامه.
- [DevTools](apps/devtools) — ابزار توسعه اندروید شامل WebView Inspector، Network، Console، Application، Elements، Sources و Performance.
- [ApiX](apps/behnam-tester) — کلاینت توسعه و تست API برای اندروید؛ شامل REST، GraphQL، WebSocket، محیط‌ها، اسکریپت، اجرای گروهی، زنجیره‌کردن درخواست‌ها، JWT Decoder و تولید کد.

هر برنامه در پوشه مستقل خودش قرار دارد و خروجی APK جداگانه تولید می‌کند.
